How this exercise works
The preview runs submitted HTML in an iframe sandbox. In this preview, document.cookie returns a simulated practice value. Calls to alert() appear in the execution log. This is a teaching simulation; the shop does not use cookie-based login.
The iframe example runs its onload handler in the preview document. With HTML escaping enabled, the same payload displays as text. Only the preview is intentionally vulnerable; your query is not stored or shared in a link.
